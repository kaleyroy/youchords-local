# 小节视图接入管线真实 downbeat 检测（作为可选来源）

## Context

小节视图（measureChartView.js）当前为**推算版**：恒定 BPM 均匀网格，BPM 由和弦变化间隔中位数估出。头部注释（measureChartView.js:6）与原设计文档已预留升级口：「管线 madmom downbeat 时间数组可替换 buildMeasures() 的均匀网格」。本次将该升级落地：

- **管线侧**（local-companion）用已装好的 madmom 增加真实 downbeat 检测（零新依赖），数据随和弦 JSON 下发
- **扩展侧**小节视图新增「来源」选择器（Auto/推算/管线，默认 Auto），管线模式下小节边界用真实 downbeat 时间（非均匀网格）

已确认的决策：管线默认开启+env 可关；旧缓存提示+一键重析；管线模式只保留 Offset 微调；来源默认 Auto。

## 数据契约（packed JSON v2 追加可选字段，不改版本号）

`/v1/results` 返回的和弦 JSON（compress_files.py `_pack_chord_timelines`）新增：

```json
"tp": 96.2,                      // 检测 BPM（拍间隔中位数换算，1 位小数）
"m": 4,                          // 检测拍号（每小节拍数，3 或 4）
"b": "512.1,500.2,498.3,501.1,…" // 全部拍点，delta编码 "deltaMs.拍位置"，位置1=downbeat
```

- 旧扩展忽略未知键、旧缓存无这些键 → 双向兼容
- 编码复用 `_encode_packed_timeline` 的 delta 模式（compress_files.py:97-109），仅把和弦索引换成拍位置
