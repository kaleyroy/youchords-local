## Context

上一轮改进后的两个收尾问题（截图）：
1. **横向滚动条**：细分落位后歌词词按设计溢入相邻空格（`inline-block + nowrap`），歌词行的内容溢出传播为 `.yc-t-sys-scroll` 的可滚动溢出 → 每个 system 下方出现横向滚动条。
2. **和弦切换点无歌词对应**：换和弦图悬在谱上方按拍对位，但用户想知道 E→B 这类切换落在哪个词上（以实际时间轴为准）——需要把换和弦时间量化到歌词细分列并就地标记。

仅改 `apps/extension/buttons/tabChartView.js`（本会话已通读全文）。

## 改动

### 1. 消除横向滚动条
- `.yc-t-lyrics` CSS 追加 `position: relative; overflow: hidden;`——词墨迹溢出不再传播为滚动区（根因）；徽标定位也需要 relative。
- `.yc-t-sys-scroll` 隐藏滚动条 UI：`scrollbar-width: none` + `::-webkit-scrollbar { display: none }`——极端情况下仍可滚轮横滚，但不再显示条。
- `fitColumnWidth`（L1108-1118）列宽下限 36→24px：窄面板也放得下整个 system，从源头减少溢出。

### 2. 和弦切换→歌词徽标（chordmark）
- `buildSystemHtml`：基于现有 `chordMarks`（换和弦点，含 col/time/gi）构建徽标层——每个 mark：`mIdx = floor(col/bpb)`、`beatCol = col%bpb`、`sub = subForBeat(sysMeasures[mIdx], beatCol, mark.time)`（复用现有细分插值函数，L606-613）、`totalSub = mIdx*bpb*div + beatCol*div + sub`；跳过 `N`/空名。徽标追加在歌词行 cells 之后：
  `<span class="yc-t-chordmark" data-time data-gi title style="inset-inline-start: calc(totalSub * var(--yc-t-colw) / var(--yc-t-div, 1))">和弦名</span>`（inset-inline-start 逻辑属性自动兼容 RTL）。
- CSS：`.yc-t-chordmark` 绝对定位 top:0、9px 粗体、1px currentColor 边框圆角、opacity 0.55、`::after` 1×5px 小竖线指向词、hover 提亮；`.yc-t-lyrics` 有徽标时加 `padding-top: 12px` 预留徽标带。
- `bindGridClicks`（L1220 区域）：`.yc-t-chordmark` 点击 → seek `data-time`。
- `updateHighlight` 和弦分支（L1330 区域）：当前和弦 `data-gi` 同时点亮对应徽标 `.yc-t-chordmark.yc-t-active`（蓝色描边），与和弦图行高亮联动。
