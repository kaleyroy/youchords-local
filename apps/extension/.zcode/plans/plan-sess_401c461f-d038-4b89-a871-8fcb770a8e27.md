# 修复模块加载失败（"Unsafe attempt to load URL"）+ Chords 按钮误报 "Only music videos…"

## Context（根因分析）

两个症状同源：**MV3 中 content script 发起的一切请求都归因到宿主页面（youtube.com），而不是扩展**：

**Bug A — 模块加载全挂**：`dynamicLoader.js:271` 用 `import(chrome.runtime.getURL(path))` 加载模块、`settingsButton.js:10` 等用 `fetch(getURL(svg))` 取资源。这类 chrome-extension:// 加载被 Chromium 按 `web_accessible_resources`（WAR）放行，属 Chrome 已知脆弱区（crbug 40196981 / 444772033）。排查确认：Chrome 153 从本仓库目录加载未打包扩展（Secure Preferences：ID `efbogjob…`、path=本仓库），manifest 的 WAR 声明覆盖全部失败路径，但实际**同目录文件一部分放行、一部分拦截**（settingsButton.js 导入成功而 index.js 失败）——该闸门在当前 Chrome 上不可靠。唯一稳妥解法是彻底不依赖它。

**Bug B — Chords 误报**：测试视频 1GWQ-oDMG6g 是 Nickelback 官方 MV（约 4 分钟、Music 分类），却弹出 "Only music videos between 15 seconds and 35 minutes are supported"——来自 `validatorModule.js` 非音乐拦截分支（`isMusicVideo()` 误判）。`isMusicVideo` 的 Step 2 请求 `https://music.youtube.com/youtubei/v1/player`：从 www.youtube.com 页面发起属**跨域**，而 Chrome 85+ 起 content script 的 fetch 按页面 CORS 规则处理（host_permissions 只豁免扩展自身上下文）→ 被阻断；Step 1（同域 www.youtube.com）对该视频未返回 Music（需用控制台 `[isMusicVideo]` 日志确认具体原因）→ 最终落入 isMusic:false → 误拦。

**附带安全问题**：WAR 把 `config/*.js` 暴露给任意 YouTube 页面脚本——`config/local-config.js` 含真实 pairing token，本次一并关闭。

## 修改内容

### A. 核心修复：所有扩展资源加载改走扩展特权通道

**1. `manifest.json`**
- `permissions` 增加 `"scripting"`
- `web_accessible_resources` 缩减为 `{"resources": ["images/*", "images/**/*", "fonts/*", "fonts/**/*"], "matches": ["*://*.youtube.com/*"]}`（移除 config/local/utils/buttons/css/data —— token 不再暴露；images/fonts 因 `<img src>`/`@font-face url()` 仍需页面可达）
- `content_scripts.js` 在 `utils/dynamicLoader.js` 前插入 `utils/loaderBridge.js`

**2. 新增 `utils/loaderBridge.js`**：`window.ycLoader = { js(path), css(path), text(path), bytes(path), postJson(url, payload) }`，经 `chrome.runtime.sendMessage` 转发后台；捕获 "Extension context invalidated" 时提示刷新页面

**3. `background.js`**（现仅 3 行，追加顶层同步注册的 onMessage 处理器）
- `YC_INJECT_JS` → `chrome.scripting.executeScript({target:{tabId: sender.tab.id}, files:[path]})`（ISOLATED world，无需 WAR，与现有 content script 同 world、`window.*` 互通）
- `YC_INJECT_CSS` → `chrome.scripting.insertCSS(...)`
- `YC_FETCH_TEXT/BYTES` → 后台 `fetch(getURL(path))`（扩展自身 origin；4MB 的 chords.complete.js 在消息上限内）
- `YC_POST_JSON` → 后台 `fetch(url, {method:'POST', body})` 返回 JSON（利用 host_permissions 的 CORS 豁免，供 Bug B 的 music.youtube.com 探测）

**4. `utils/dynamicLoader.js`**：`loadFile` 的 `import(url)` → `await ycLoader.js(path)`（保留 loaded Set 去重、重试、aborted 逻辑）；`loadCSS` → `ycLoader.css` + Set 去重；`isCSSLoaded` 改查 Set；`prefetchShared` 删除 prefetch `<link>` 创建改为空转；`MODULE_GROUPS.auth.files` 改 `['config/local-config.js', 'local/auth.js']` 保证顺序

**5. 散落调用点机械替换**（import() → ycLoader.js；fetch(getURL) → ycLoader.text/bytes；`<script>/<link>` 注入 → ycLoader.js/css）：
- `settingsButton.js` :10、:2714/:2843/:2870；`chordsButton.js` :58；`subtitleButton.js` :2703、:3086（解构改读 window）
- `lyricsAndChordsButton.js` :1470/:1539、:3547、:9529（改用已有 `window.chordRenderer` 判断）、:9705、:11685、:11701
- `subtitleMenu.js` :294（改读 `window.createSubtitleLocationSubmenu`）
- `validatorModule.js` :814（改读 `window.getLocalDuration`）、`extractorModule.js` :1679、`youtubeSubtitles.js` :59、`chordExplorer.js` :838（读 `window.COMPLETE_CHORDS`）
- `content.js` :764/:943（.json.gz 用 bytes）
- `audioManager.js` :52、`tuner.js` :1615（pitch-shifter 改注入 ISOLATED world，与调用方同 world）
- `carouselSubtitlesFontMenu.js` :56、`lyricsAndChordsFontMenu.js` :62（fonts CSS 改 insertCSS；@font-face 字体仍走页面加载，fonts 保留 WAR）

**6. 去 ESM 化**（executeScript 按 classic script 执行，含 import/export 语句会 SyntaxError）：
- `config/local-config.js` + `local-config.example.js`：`export const LOCAL_CONFIG` → `window.YC_LOCAL_CONFIG = Object.freeze({...})`（**保持 REPLACE_DURING_INSTALL 占位符不变**，install.ps1 依赖它）
- `local/auth.js`：删顶部 import → `const LOCAL_CONFIG = window.YC_LOCAL_CONFIG;`；删 :185 export 块（确认已有 `window.ycAuth` 赋值）
- `subtitleLocationMenu.js`：去 10 处 `export`，为 3 个被消费函数补 `window.*` 赋值
- `videoMetaLocal.js`：去 export，补 `window.getLocalDuration = getLocalDuration`
- `validatorModule.js`（2 处）、`extractorModule.js`（~12 处）、`youtubeSubtitles.js`（:2197 export 块）、`chordRenderer.js`（default export；确认 `window.chordRenderer` 已赋值）：纯删 `export` 关键字
- `data/chords.complete.js`：核实无 export 语句

### B. 修复 Chords 误报（validatorModule.js）

- `isMusicVideo` Step 2 的 `music.youtube.com/youtubei/v1/player` 两个重试 fetch → `ycLoader.postJson(url, musicPayload)`（后台执行，host_permissions 豁免 CORS）

- 验证时读控制台 `[isMusicVideo]` 逐步日志确认 Step 1 为何未返回 Music；若另有原因（如响应缺 category）再对症处理
