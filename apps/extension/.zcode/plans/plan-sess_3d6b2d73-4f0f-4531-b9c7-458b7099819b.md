# 小节视图 (Measure View) — 推算版:按小节展示和弦并与歌词同步

## Context

新增一种"按小节展示和弦"的布局,与歌词同步高亮,**不影响现有任何功能**。经确认:本次落地**扩展内推算版**(恒定 BPM 均匀网格),本地管线 madmom downbeat 真实检测留作后续增强(数据结构预留 beats 时间数组入口)。

现状(已探明):
- 代码库无任何 BPM/拍号/小节数据;和弦是 `时间秒:和弦名` 扁平列表(`chordsDisplay.js:229` 解析),轮播蓝色方块是硬编码 0.5s 格(`chordCarousel.js:366`),与音乐节拍无关
- 歌词有逐词时间戳:`combineLyricsAndChords()`(`lyricsAndChordsButton.js:4622`)返回 `combinedData`,每行含 `wordChordPairs[]` = `{word:{word,start,end}, chords:[{name,time}], isChordGap}`
- 架构:window 全局 + CustomEvent(`yc:timeUpdate`/`yc:modeChanged`/`yc:capoChanged`/`yc:panelClosing`),模块经 `utils/dynamicLoader.js` MODULE_GROUPS 懒加载

## 小节切分算法(推算版)

1. **初始 BPM 估算**:相邻和弦间隔取中位数 `median(Δ)` → 假设每小节 2 次换和弦 → `BPM = 60 × beatsPerBar / (2 × median)`,夹取 [40, 240],用户可 ×2/÷2 修正倍频歧义或手输精确值
2. **均匀网格**:`beatDur = 60/BPM`;`measureDur = beatDur × beatsPerBar`;`measureStart(n) = offset + n × measureDur`;`measureIndex(t) = floor((t − offset) / measureDur)`
3. **装格**:和弦 → 小节号 + 拍位 `floor((time − measureStart)/beatDur)`(offset 前钳到第 0 小节,同拍多和弦按时间并列,空小节画空格);歌词词 → `measureIndex(word.start + 字幕偏移)`(与面板高亮口径一致)
4. **同步**:`video.currentTime → measureIndex → 当前小节格高亮`,格内二分查找当前和弦拍位与当前词
5. **预留升级**:measure 边界函数收敛在一处,未来替换为管线 downbeat 时间数组查表

## 实现

### 1. 新文件 `buttons/measureChartView.js`(约 600 行,核心工作量)

IIFE + `/* yc-module-scope */`,暴露:
```js
window.ycMeasureChart = { toggle, isEnabled, onContentRendered, updateHighlight, onPanelClosing }
window.toggleMeasureView
```

- **设置持久化**(不动 IndexedDB obfuscated schema):每视频 `chrome.storage.local` 键 `yc_measure_<videoId>` = `{bpm, beatsPerBar, offset}`;全局开关 `chrome.storage.sync` `measureViewEnabled:false` 镜像 `window.measureViewEnabled`(沿用 `beatGridEnabled` 模式)
- **工具条**(仅本视图内):BPM 数字输入 + ×2/÷2、拍号选择(3/4/6)、Offset ±0.5s、Auto BPM 估算按钮,改动即时重渲
- **网格**:CSS grid 每行 4 小节格;格内上行按拍位排和弦、下行排该小节歌词词;当前小节 `.active` 蓝框(`#3ea6ff`)+ 当前词/和弦加亮;继承面板主题类(black/sepia/light)与 RTL 方向;和弦名经 `window.getCapoChord(name,'panel')` + `chordRenderer.getDisplayChordName`(同 `chordsPreviewPanel.js:5465-5467`)
- **空态**:无歌词仅显示和弦行;无和弦显示提示
- **交互**:自动滚动到当前小节(尊重面板 Auto scroll 开关);词/小节点击跳转 `video.currentTime`
- **事件补发**:接管高亮后,`ycChordsPreviewPanel?.isVisible` 时须 dispatch `yc:timeUpdate {time, isScrubbing:false}`(原逻辑在 `lyricsAndChordsButton.js:7840-7846`,提前 return 会跳过)
- **监听**(模块自挂):`yc:modeChanged`/`yc:capoChanged` → 重渲染;`yc:panelClosing` → 清理;`yc:timeUpdate`(isScrubbing)→ 拖动即时高亮
